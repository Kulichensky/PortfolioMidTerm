## 2. HTML (Разметка)
> **Спросят: «Какая здесь структура и семантика?»**
> «Я использовал стандартные семантические теги HTML5:
> * `<header>` — шапка с логотипом `nurda`, навигацией и кнопками смены темы и бургера.
> * `<nav>` — навигационное меню (`Home`, `About`, `Contact`).
> * `<main>` — главный контент, разделённый на 3 секции:
>   * `<section id="hero">` — первый экран с приветствием и карточкой-иллюстрацией.
>   * `<section id="about">` — секция обо мне с фото и цифрами опыта.
>   * `<section id="contact">` — форма обратной связи и вторая иллюстрация.
> * `<footer>` — подвал сайта с копирайтом.
> * `<div id="resume-modal">` — модальное окно для резюме.»

> **Спросят: «Где теги label у полей формы?»**
> «У каждого поля формы есть связанный тег `<label for="...">`, где `for` совпадает с `id` инпута (например, `for="email"` и `id="email"`). Чтобы дизайн оставался минималистичным, как в моём макете, я скрыл текст надписей с помощью класса `.visually-hidden`. Так верстка выглядит красиво, но полностью доступна для скринридеров и проверяющих.»

## 3. Что говорить по CSS (Стили и адаптив)
> **Спросят: «Почему нет горизонтальной прокрутки?»**
> «Во-первых, в глобальном сбросе `*` я задал `box-sizing: border-box`, поэтому padding и border не увеличивают ширину блоков. Во-вторых, на `body` стоит `overflow-x: hidden`. В-третьих, на экранах меньше 768px (`@media (max-width: 768px)`) все двухколоночные блоки перестраиваются в одну колонку через `flex-direction: column`.»

> **Спросят: «Как сделана тёмная тема в CSS?»**
> «Через переменные в `:root`. По умолчанию на сайте светлый фон `--bg: #FFFFFF`. Когда через JavaScript на `body` вешается класс `dark-theme`, переменные переопределяются: фон становится тёмным `--bg: #1A202C`, а текст белым `--text-main: #FFFFFF`.»

## 4. Что говорить по JavaScript (Всего 4 простые функции!)

В файле `main.js` ровно 4 понятные функции, которые легко показать:

### Функция 1: Мобильное меню (строки 8–28)
* Находим кнопку бургера `burgerBtn` и меню `navMenu`.
* По клику делаем `navMenu.classList.toggle('open')`.
* Если класс `open` есть — ставим картинку крестика `media/close.png`, если нет — возвращаем `media/burger.png`.
* При клике на любую ссылку меню закрывается.

### Функция 2: Переключение темы (строки 33–54)
* По клику на кнопку `themeBtn` делаем `document.body.classList.toggle('dark-theme')`.
* Меняем картинку: если тема тёмная — ставим солнце `media/sun.png`, если светлая — луну `media/moon.png`.
* Запоминаем выбор в `localStorage.setItem('site-theme', ...)` — при перезагрузке тема сохраняется.

### Функция 3: Модальное окно Resume (строки 59–85)
* При клике на кнопку «Resume» добавляем класс `open`: `modal.classList.add('open')`.
* При клике на крестик, клике на темный фон или нажатии клавиши `Escape` убираем класс: `modal.classList.remove('open')`.

### Функция 4: Валидация формы (строки 90–150)
* По нажатию на «Send Message» отменяем перезагрузку страницы через `e.preventDefault()`.
* Проверяем поле имени: если пустое — пишем в span `nameError.textContent = 'Введите ваше имя'`.
* Проверяем email: если пустой или нет знака `@` (`!emailInput.value.includes('@')`) — выводим ошибку.
* Проверяем сообщение: если пустое — выводим ошибку.
* Если всё заполнено верно — показываем зелёный блок `formSuccess.style.display = 'block'` и очищаем форму через `contactForm.reset()`.

## 5. Если преподаватель скажет: «Измени что-нибудь прямо сейчас при мне»

### Задание: «Поменяй основной цвет сайта (кнопок)»
1. Открой `style.css`.
2. В строке 6 найди `--primary: #0F5257;`.
3. Замени код цвета на любой, например:
   * `#2563EB` (синий)
   * `#E11D48` (красный)
   * `#059669` (зелёный)
4. Сохрани файл и обнови страницу — цвет поменяется везде сразу!

### Задание: «Измени текст ошибки в форме»
1. Открой `main.js`.
2. Найди строку 112: `nameError.textContent = 'Введите ваше имя'`.
3. Напиши свой текст, например: `'Пожалуйста, укажите имя!'`.

### Задание: «Добавь ещё одну плашку навыка в модалку (например, REACT)»
1. Открой `index.html`.
2. Найди блок `.skills-grid` (строка ~155) и добавь строку:
   ```html
   <div class="skill-pill">REACT</div>
   ```
3. Сохрани и открой модалку — плашка уже там.
